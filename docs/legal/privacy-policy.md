## 1. Information we collect

### Information you provide to us

When you create an account or interact with the Services, you may provide:

- Your name and email address, entered by you or supplied by GitHub or Google when you sign in with them
- Your profile picture address, if your sign-in provider supplies one
- A salted password hash, only if you create an account with email and password (we never store the password itself)
- The link between your account and your GitHub or Google identity, including the access tokens those providers issue to us

### Content you create

You may create content within the Services, such as:

- The app name, app address, and description you add to your developer profile
- The names and allowed website origins you give your API keys

### Information collected automatically

When you use the Services, we automatically collect:

- The IP address and browser user agent of each signed-in session
- For API requests made with your keys: the key, time, method, path, status code, response time, user agent, and IP address. These request logs are kept for 90 days and then summarized into daily totals per key
- For API requests made without a key: the IP address (IPv6 addresses are grouped by their first 64 bits), held only in short-lived rate-limit counters that reset within a day. These requests are not logged individually

### Information from third-party services

You may sign in using a third-party identity provider. When you do, we receive basic profile information from that provider. The information we receive depends on your settings with the provider. Identity providers we support:

- GitHub
- Google
- Email and password, where the operator has enabled it
